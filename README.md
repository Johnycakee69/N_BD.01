# Birthday Site for Pheak Sophatnita ♥

An interactive birthday celebration page featuring animated cake candles, confetti, Jungkook birthday animation, and photo collage with lightbox.

## How to Host on Render (Free & 1-Click)

This project is a static website and hosts completely free on [Render](https://render.com).

### Method 1: Automatic Blueprint (Easiest)
1. Push this repository to GitHub.
2. Go to the [Render Dashboard](https://dashboard.render.com).
3. Click **New +** > **Blueprint**.
4. Connect this GitHub repository (`N_BD`).
5. Render will automatically detect `render.yaml` and configure the static site.
6. Click **Apply**. Done!

---

### Method 2: Manual Static Site
If you prefer setting it up manually without Blueprints:
1. In Render Dashboard, click **New +** > **Static Site**.
2. Connect your GitHub repository (`N_BD`).
3. Set the following options:
   - **Name**: `birthday-site` (or whatever you like)
   - **Branch**: `main`
   - **Root Directory**: *(leave blank)*
   - **Build Command**: *(leave blank)*
   - **Publish Directory**: `.` *(type a single dot)*
4. Click **Create Static Site**.
